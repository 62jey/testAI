# Four-strategy selection

The analyser and scanner allow the user to choose one strategy group before requesting analysis:

1. **AOL / TAOL** — liquidity area reaction, sweep, BOS, displacement and retest.
2. **XAU Bible** — gold-focused H4, H1 and M15 confirmation model.
3. **Candlestick Bible** — trend, support/resistance rejection, pin bars and engulfing patterns.
4. **ICT / SMC** — liquidity, BOS/MSS, displacement, FVG, order block and OTE.

**Compare All Four** runs every module independently and returns the highest-scoring valid conclusion. Every journal record stores the requested strategy and the primary strategy selected by the engine.
